# TeamDocs resource documents

These files are the runtime snapshot of the three canonical documents in the repository root:

- `docs/cost-tracking-rules.md`
- `docs/leantime-zh-guide.md`
- `docs/leantime-zh-glossary.md`

When the canonical files change, run the repository's TeamDocs sync check and commit both copies. The plugin reads only this directory at runtime; it never reads the repository root `docs/` directory.
