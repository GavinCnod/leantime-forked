# 团队费用记账规矩

> 适用范围:本团队在 Leantime 上记录、归属、核对项目费用。
> 配套文档:`docs/leantime-zh-guide.md`(工具怎么操作)、`docs/leantime-zh-glossary.md`(术语对照)。
> 最后更新:____(你填日期)

## 目的

解决三个问题:
1. 负责人不知道钱花在哪、花了多少("事后很久才告诉我")
2. 费用归不到正确项目(该 A 的记成 B,该分摊的记成单个项目)
3. 两人记同一笔、遗漏、补记靠回忆

规矩本身不改工具,只定"谁记、何时记、归到哪、怎么不记重、怎么核对"。

---

## 关键定义(先读这段,所有人理解一致)

### 经手人

**经手人 = 实际下单或付款的那个人。** 一笔费用有且只有一个经手人,由他在自己负责的那张任务上记账。

- 不是老板付的款就算老板,也不是助理代下单就算助理 —— 以"谁触发了这笔支出"为准。
- 经手人不确定的,当场在群里 @ 相关人确认,不要两人各记各的。

### 归属项目

这笔费用服务的是哪个客户/项目,就归到那个项目。

- 一笔费用同时服务 ≥2 个项目(域名、服务器、团队共同采购):按**平均分摊**处理。算出每个项目的份额,在每个项目的对应任务上各记一笔实际成本,备注写"分摊自{费用描述} {日期} {发票号}"。
- 不服务任何客户项目的费用(办公采购、团队餐、纯内部工具):归入专门的 **"内部开销"项目**(项目名你们自己定,建议就叫"内部开销"),经手人在该项目的固定"费用登记"任务上记账,不要散到各处。

### 垫付前不审批

现状是事后记录。本规矩**不增加事前审批环节**,只规范"发生后怎么记、归到哪、谁记"。

## 记账节奏

### 产生即记(经手人)

- 经手人在**当周内**把这笔费用记到对应任务的"实际成本"字段上。
- 备注格式:`{月-日} {费用类型} 垫付 {可选:发票号}`。例:`09-02 样品费 垫付 发票号AB123`。
- 补记必须标注:`补记 {原发生日期} {费用类型} ...`,让负责人能看出这笔是事后补的。

### 每周固定核对(负责人)

- **每周固定一天下午**(默认建议周五,团队定死某一天后写进这里),负责人打开每个项目,在项目页面找与 **项目详情 / 成员 等并列的"成本"tab**,核对三件事:
  1. 本周是否有超预算项目(对比预算使用率、预算剩余、超支金额)
  2. 是否有归属存疑的费用(备注不清晰或项目选错的)
  3. 是否有"补记"未消化的费用(备注里的原发生日期和记账时间差很大)
- 任何异常当场在群里 @ 相关经手人改,不要攒到下周。
- 核对日定了就写死在下面:

  > **本团队每周核对日:____**(待定,填进去)

## 费用类型 → 归属项目 映射表

> ⚠ **本表为初始示例,不是终稿。** 团队本周内必须按真实出现的费用类型补齐此表(注意别漏:通信工具订阅费、差旅费、培训费、软件许可证、外部顾问费、水电物业费…),补全前遇到表外类型一律走"其他(表外)"兜底行,不要硬塞进现有几类。

| 费用类型 | 归属规则 | 示例 |
|---|---|---|
| 客户沟通费 | 对应客户的当前项目 | A 客户拜访产生的打车/电话费 → A 客户项目的对应任务 |
| 样品费 | 下单项目 | 给 A 客户做的样品 → A 客户项目 |
| 物流费 | 对应订单项目 | A 客户的发货运费 → A 客户项目 |
| 域名/服务器费 | 平均分摊到使用该服务的项目;纯内部归"内部开销" | 服务 A、B 两项目的服务器 ¥3000 → A、B 各记 1500 |
| 团队共同采购 | 归"内部开销"项目 | 办公文具、团队餐 |
| 其他(表外)费用 | 待定:经手人当场群内 @ 负责人裁定归属,裁定结果补回本表 | 某个新出现的订阅服务 |

## 防重复(两人记同一笔)

- **唯一经手人原则**:一笔费用只有一个经手人(谁下单/付款谁记)。经手人不确定时群里 @ 当场确认。
- **周会口头对账**:每周核对时,各经手人报"本周记了哪几张发票号",负责人当场听。如果同一张发票号被报两次,让一人删掉、另一人留。

> **能力边界(重要,先说清楚)**:当前 CostTracking 插件**无法在界面上跨任务查看 free-text 备注**,负责人在"成本"tab 里看不到具体是哪个任务记了什么备注。所以"发现重复"这一步目前只能靠上面的周会口头对账,**不是系统约束**。去重约束需要插件后续改动(加跨任务备注索引 / 发票号唯一性),本次不做。若团队真跑起来发现口头对账不够用,再立项做插件改动。

## 内部开销项目的维护规矩

- "内部开销"项目里放一张**固定的"费用登记"任务**,所有内部开销(办公采购、团队餐、纯内部工具)都记在这张任务上。
- **这张任务不要删除或关闭**:任务被删时,该任务上累计的成本会被级联删除,累计金额就没了。若确需重建,先把历史累计手动记到新任务上,再删旧的。
- 新人第一次填时,若该任务还没有成本,在任务表里可能看不到(零成本任务默认隐藏),直接按任务名搜索"费用登记"找到它即可。

## 负责人每周核对操作(速查)

每周核对日那天下午,对每个项目:

1. 进项目页 → 点"成本"tab(与"项目详情/成员"等并列)
2. 看三个数字:**预算使用率(按实际成本)、预算剩余、超支金额**
3. 切 **统计范围**(默认"顶层任务";要看子任务分摊的细节就切"子任务")
4. 有超支 / 归属存疑 / 大量补记的,当场群里 @ 经手人改
5. 各经手人口头报本周发票号,听有没有记重

## 新人入职

1. 发 `docs/leantime-zh-guide.md`(工具怎么用)+ 本文件(规矩)。
2. 指定一个老成员陪记第一笔真实费用,当场过一遍"经手人 → 归属项目 → 备注格式"。
3. 第一周由负责人多看一眼他的记录。
