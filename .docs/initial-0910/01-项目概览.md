# 01 项目概览

## 1.1 项目定位

Leantime 是一个开源的**项目管理与创新管理**系统，官方定位是"为非项目经理设计"。它将战略（战略画布/目标/OKR）、规划（迭代/里程碑/甘特图）与执行（看板/任务/工时）整合在一个工具里，并特别关注 ADHD、阅读障碍、自闭症等神经多样性人群的可及性（大字模式、Atkinson Hyperlegible 字体等）。

- 官网：https://leantime.io
- 上游仓库：https://github.com/Leantime/leantime
- 本 fork：`git@github.com:GavinCnod/leantime-forked.git`（origin）
- 许可证：AGPL-3.0-only（[LICENSE](LICENSE)）——二开若对外提供服务需注意 AGPL 传染性条款

## 1.3 Fork 状态

- `git status` 干净，**无任何本地改动**——这是一个纯上游快照，二开从零开始。
- `app/Plugins` 是 git submodule（`git@github.com:Leantime/plugins.git`，商业插件私库），**未初始化**（`git submodule status` 前缀 `-`）。OSS 功能不依赖它；不要 `git submodule update --init`（会拉私有仓库，大概率无权限）。

## 1.4 功能清单（OSS 版全含）

**任务管理**：看板、甘特图、表格、列表、日历四种视图；无限子任务、任务依赖、里程碑管理、迭代（Sprint）管理、时间追踪与工时表。
**项目规划**：项目仪表盘、报告与状态更新、目标与指标追踪（OKR 风格）、精益/商业模式画布、SWOT 分析画布、风险分析。
**知识管理**：Wiki/文档、点子看板、回顾会议（Retrospective）、文件存储（S3 或本地）。
**管理能力**：多角色与项目级权限、双因素认证（TOTP）、LDAP / OIDC 登录、插件系统、JSON-RPC API + MCP AI 工具、Slack/Mattermost/Discord 通知、20+ 语言。

## 1.5 运行环境要求

- PHP 8.2+（需要 bcmath、ctype、curl、dom、exif、fileinfo、filter、gd、hash、**ldap**、mbstring、mysqli、opcache、openssl、pcntl、pcre、pdo、phar、session、tokenizer、zip、simplexml 扩展）
- MySQL 8.0+ / MariaDB 10.6+（或 PostgreSQL，`LEAN_DB_DEFAULT_CONNECTION=pgsql`）
- Apache 或 Nginx（web 根目录指向 `public/`）
- Node ≥ 18（仅构建时需要）
