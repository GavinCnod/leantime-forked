# 03 配置系统

## 3.1 配置来源与优先级

配置由自定义 bootstrapper `LoadConfig`（[app/Core/Bootstrap/LoadConfig.php](app/Core/Bootstrap/LoadConfig.php)）加载，优先级从高到低：

```
环境变量（真实 env / 服务器变量） > config/.env 文件 > PHP 配置类默认值（DefaultConfig）> 代码内兜底
```

- `Environment`（[app/Core/Configuration/Environment.php](app/Core/Configuration/Environment.php)）是**配置仓库本身**（替代 Laravel 标准 `Repository`），读取 `config/configuration.php`（若存在）、`configuration.yml` 或 `LEAN_*` 环境变量。
- 用户可编辑变量的模板在 [config/sample.env](config/sample.env)（全部 `LEAN_` 前缀，约 220 行）。
- 默认值类：[DefaultConfig.php](app/Core/Configuration/DefaultConfig.php) —— 字段带 `#[LaravelConfig('dotted.key')]` 属性映射到 Laravel 配置键。

**关键警告**（[CLAUDE.md:235-237](CLAUDE.md#L235)）：所有 Laravel 配置（database、cache、session、auth、sanctum、sentry…）都集中在**单个文件** [app/Core/Configuration/laravelConfig.php](app/Core/Configuration/laravelConfig.php)（约 1000 行），**不存在** `config/*.php` 散文件。因此 `artisan config:publish` 之类命令无效；新增 Laravel 配置必须写进 laravelConfig.php。同时**不要**在根 `config/` 下新建自定义 PHP 配置，二开新增配置项的标准做法：

1. 在 [DefaultConfig.php](app/Core/Configuration/DefaultConfig.php) 加 `public mixed $xxx = 默认值;` 并加 `#[LaravelConfig('xxx.key')]` 属性；
2. 在 [config/sample.env](config/sample.env) 加 `LEAN_XXX = ...` 注释说明。

## 3.2 关键配置段速查（sample.env）

### 基础
- `LEAN_APP_URL` / `LEAN_APP_DIR`：子目录部署用
- `LEAN_DEBUG = 0`
- `LEAN_PERMISSIONS_ENFORCE = true`：权限强制开关（`false` 时只审计不拦截）
- `LEAN_SITENAME`、`LEAN_LANGUAGE`、`LEAN_DEFAULT_TIMEZONE`
- `LEAN_LOG_CHANNELS = single,syslog,sentry`、`LEAN_LOG_PATH`

### 数据库
- `LEAN_DB_HOST/USER/PASSWORD/DATABASE/PORT`
- `LEAN_DB_DEFAULT_CONNECTION = mysql|pgsql`（PostgreSQL 附加 `LEAN_DB_SCHEMA`、`LEAN_DB_SSLMODE`）
- 连接池：`LEAN_DB_PERSISTENT_CONNECTIONS`、`LEAN_DB_MAX_CONNECTIONS`、`LEAN_DB_MIN_CONNECTIONS`、`LEAN_DB_CONNECTION_TIMEOUT`、`LEAN_DB_IDLE_TIMEOUT`

### 会话与安全
- `LEAN_SESSION_PASSWORD`（会话盐，**必须改**）、`LEAN_SESSION_EXPIRATION = 480`（分钟）
- `LEAN_SESSION_SECURE`、`LEAN_HSTS_ENABLED`
- Redis：`LEAN_USE_REDIS`、`LEAN_REDIS_*`（注意 `LEAN_REDIS_SESSION_DB=1` 与缓存库隔离，防 FLUSHDB 误杀会话）

### 限流（每分钟）
- `LEAN_RATELIMIT_GENERAL=2000`、`API=120`、`AUTH=20`（登录）、`MCP=300`、`SIGNUP=5`、`INVITES_USER=10/小时`、`INVITES_TENANT=30/天`

### 外观
- `LEAN_LOGO_PATH`、`LEAN_DEFAULT_THEME`、`LEAN_PRIMARY_COLOR`、`LEAN_SECONDARY_COLOR`

### 文件存储
- 本地：`LEAN_USER_FILE_PATH='userfiles/'`、`LEAN_DB_BACKUP_PATH='backupdb/'`
- S3：`LEAN_USE_S3`、`LEAN_S3_KEY/SECRET/BUCKET/REGION/FOLDER_NAME/END_POINT/USE_PATH_STYLE_ENDPOINT`

### 邮件
- `LEAN_EMAIL_RETURN`、`LEAN_EMAIL_USE_SMTP`、`LEAN_EMAIL_SMTP_*`（hosts/auth/username/password/tls/secure/port）

### 认证
- LDAP：`LEAN_LDAP_USE_LDAP`、`LEAN_LDAP_TYPE=OL|AD`、`LEAN_LDAP_HOST/PORT/URI/DN`、`LEAN_LDAP_KEYS`（字段映射 JSON）、`LEAN_LDAP_GROUP_ASSIGNMENT`（组→角色 JSON）、`LEAN_LDAP_DEFAULT_ROLE_KEY=20`
- OIDC：`LEAN_OIDC_ENABLE`、`LEAN_OIDC_CLIENT_ID/SECRET`、`LEAN_OIDC_PROVIDER_URL`、`LEAN_OIDC_CREATE_USER`、`LEAN_OIDC_DEFAULT_ROLE=20`、`LEAN_OIDC_*_OVERRIDE`、字段映射等

### 其他
- `LEAN_NEWS_ENABLED`（内网/离线环境可关新闻服务）

## 3.3 与旧 configuration.php 的关系

根 [config/configuration.sample.php](config/configuration.sample.php) 是历史遗留的 Config 类模板（含 `sessionExpiration=28800s` 等旧键）。运行时若存在 `config/configuration.php` 会被 `Environment` 加载（[Environment.php:75-83](app/Core/Configuration/Environment.php#L75)），但新开发一律走 `LEAN_*`。

## 3.4 AppSettings（版本信息）

[AppSettings.php](app/Core/Configuration/AppSettings.php) 只有两个公开属性：

```php
public string $appVersion = '3.9.8';   // 应用版本
public string $dbVersion = '3.5.26';   // 数据库版本（决定升级脚本跑哪些）
```

数据库升级脚本的版本编号规则：`A.BB.CC` → 整数 `ABBCC`（如 3.04.08 → `30408`），维护在 [Install/Repositories/Install.php:45](app/Domain/Install/Repositories/Install.php#L45) 的 `$dbUpdates` 数组中（从 `20004` 到 `3xx` 共 30+ 项）。
