# 08 认证与权限

## 8.1 认证流程总览

**中间件链**（见 [02-架构总览](02-架构总览.md) §2.4）：`StartSession` → `AuthCheck`（门禁）→ `AuthenticateSession`（构造 `session('userdata')`）。

### 登录（app/Domain/Auth）
- 控制器：[Login.php](app/Domain/Auth/Controllers/Login.php)（post 表单）→ [Services/Auth.php](app/Domain/Auth/Services/Auth.php):144-246：
  1. 若启用 LDAP 且可连接 → LDAP 认证（用户不存在自动建号）；
  2. 否则 DB 认证 `getUserByLogin` + `password_verify`。
- 成功后 `UserSessionBuilder::build()`（[UserSessionBuilder.php](app/Domain/Auth/Services/UserSessionBuilder.php):36-55）构造 `session('userdata')`，**role 恒为角色名字符串**（`Roles::getRoleString()`）——这是 Web / x-api-key / Bearer 三条路径的单一事实源（3.9.x 曾因 Bearer 路径存数字 int 导致权限全拒的回归，勿重蹈）。
- 登录态会话 id 写入 DB（`updateUserSessionDB`）；登出调 `invalidateSession`。
- 公开路由白名单（[AuthCheck.php:25-45](app/Core/Middleware/AuthCheck.php#L25)）：`auth.login`、`auth.resetPw`、`auth.userInvite`、`install`、`oidc.*`、`auth.callback/redirect`、`cron.run`、`calendar.ical` 等，可经 `dispatchFilter('publicActions')` 扩展。

### 会话
- 驱动：默认 file（`storage/framework/sessions`），`LEAN_USE_REDIS` 时切 Redis（会话与缓存分库）；API/CRON 请求自动降级为内存 array 驱动（[StartSession.php:65-68](app/Core/Middleware/StartSession.php#L65)）。
- Web 会话"乐观并发"：不加锁执行，结束时 diff 会话键在锁下合并写回（防止并发请求互相覆盖）；`storeCurrentUrl` 跳过 HTMX 局部请求（[StartSession.php:121-210,372-384](app/Core/Middleware/StartSession.php#L121)）。
- 空闲过期 `LEAN_SESSION_EXPIRATION = 480` 分钟。

### 三个 auth guard（[laravelConfig.php:678-700](app/Core/Configuration/laravelConfig.php#L678)）
| guard | 用途 | 实现 |
|---|---|---|
| `leantime` | Web 会话 | `Guards\WebGuard` |
| `jsonRpc` | x-api-key API Key | `Guards\ApiGuard` |
| `sanctum` | Personal Access Token | Laravel Sanctum（定制模型） |

注册见 [AuthenticationServiceProvider.php:112-131](app/Core/Auth/AuthenticationServiceProvider.php#L112)。

## 8.2 角色体系

- 角色常量（[Domain/Auth/Models/Roles.php](app/Domain/Auth/Models/Roles.php):27-34）：`readonly=5`、`commenter=10`、`editor=20`、`manager=30`、`admin=40`、`owner=50`（DB 存数字，会话存名字符串）。
- 用户可在项目级获得不同角色：`zp_relationuserproject.projectRole`；`RoleResolver`（[app/Core/Auth/RoleResolver.php](app/Core/Auth/RoleResolver.php)）解析有效角色：manager 及以上全局角色在所有项目生效；项目角色缺省继承全局。
- 项目可见性：全员可见 / 仅客户（client）内可见 / 仅直接分配用户可见；admin 与 owner 可访问全部项目。
- 旧式角色判断辅助（仍在用）：`Auth::userIsAtLeast()`、`authOrRedirect()`、`userHasRole()`（[Auth.php:589-644](app/Domain/Auth/Services/Auth.php#L589)）。

## 8.3 权限系统（新式，推荐）

### `#[RequiresPermission]` 属性
```php
#[RequiresPermission(permission: TicketsPermissions::CREATE, projectIdParam: 'projectId')]
public function create(array $params) { ... }
```
- 参数：`permission`（`domain.action` 键）、`projectIdParam`（从请求参数取项目 id）、`global`（公司级能力，按全局角色判）、`entityScoped`（方法体自行 `$this->authorize()`）。
- 在三个入口统一由 `PermissionEnforcer`（[PermissionEnforcer.php](app/Core/Auth/Permissions/PermissionEnforcer.php):43-96）执行：Frontcontroller 执行、CheckPermissions 中间件（Laravel 路由）、JsonRpc 执行。
- 未标注 = no-op；拒绝抛 `AuthorizationException` → Web 403 / RPC **-32001**；`projectIdParam` 声明但无法解析且参数必需时 **fail-closed**。
- 审计模式：`LEAN_PERMISSIONS_ENFORCE=false` 时只记日志不拦截（默认 true）。

### 权限词汇表（DB 驱动）
- 各域声明 `app/Domain/{X}/Permissions/{X}Permissions.php`（实现 `ProvidesPermissions`，如 [TicketsPermissions.php](app/Domain/Tickets/Permissions/TicketsPermissions.php)：`tickets.view/comment/upload/create/edit/delete`）。
- `PermissionRegistry` 自动发现聚合 → `PermissionSeeder` 写入 `zp_permissions`。
- 默认角色授权矩阵在 `DefaultRolePermissions`（按 level 递进 union：readonly → commenter → editor → manager → admin → owner）。
- 运行判定 `PermissionService::currentUserCan()`（[PermissionService.php](app/Domain/Auth/Permissions/PermissionService.php):56-79）= 角色→权限映射 + 项目数据访问判定；缓存于 installation store（`leantime.permissionMap`），修改后 `flushCache()`。

### 同步命令
```
php bin/leantime permissions:sync [--seed] [--prune]
```
将代码声明的词汇表幂等同步到 DB；`--seed` 补角色默认授权（增量，不覆盖自定义）；`--prune` 删除孤儿权限。

## 8.4 API 认证（详见 [09-API与MCP](09-API与MCP.md)）

1. **Leantime API Key**：`x-api-key` 头，格式 `lt_{user}_{key}`，`password_verify` 校验（[Api.php:56-86](app/Domain/Api/Services/Api.php#L56)），等同服务账号。
2. **Bearer Token（自研）**：`php bin/leantime auth:create-bearer-token --email=...` 签发；`Str::random(40)` 明文返回，库中只存 **sha256**（[AccessTokenRepository.php:24-43](app/Domain/Auth/Repositories/AccessTokenRepository.php#L24)），不是 Sanctum 的 `{id}|{plaintext}` 格式，由 `AuthCheck::authenticateApi` 直接调 `Auth::getUserByToken()` 校验（支持 `expires_at`）。

## 8.5 其他认证方式

- **LDAP**（[Domain/Ldap/Services/Ldap.php](app/Domain/Ldap/Services/Ldap.php)）：OpenLDAP/Active Directory，属性映射 `LEAN_LDAP_KEYS`、组→角色 `LEAN_LDAP_GROUP_ASSIGNMENT`。
- **OIDC**（[Domain/Oidc/](app/Domain/Oidc/)）：自动发现 + JWKS 验签，控制器 Login/Callback/Mobile（App 免密），字段映射可配；`oidcCreateUser` 可自动建号，默认角色 20。
- **2FA**（[Domain/TwoFA/](app/Domain/TwoFA/)）：TOTP（RobThree），`AuthCheck` 未验证时强制跳 `twoFA.verify`；token 类认证默认视为已验证（令牌即强凭据）。
- **SAML2** 等更多 provider：通过 Laravel Socialite（Authentik/Auth0/Gitea/GitHub/GitLab/Google/Keycloak/Microsoft/Okta/PropelAuth/EduID）。

## 8.6 密码重置

- `POST /auth/resetPw`（公开路由）：`generateLinkAndSendEmail()`（[Auth.php:383-414](app/Domain/Auth/Services/Auth.php#L383)）——限 5 次（`pwResetLimit`），32 位随机链接落库（`pwReset` 哈希 + 1 小时过期 + 计数），无论账号是否存在都返回成功（防枚举），邮件直发。
- `resetPassword()`：校验强度（≥8 位含大小写/数字/特殊字符）→ `password_hash(PASSWORD_DEFAULT)` 更新 → 清空重置字段 → 更新 `lastpwd_change`。
