## 2.3 启动流程（请求生命周期）

1. **`public/index.php`**（[index.php](public/index.php)）：定义 `RESTRICTED`、加载 [app/helpers.php](app/helpers.php)、composer autoload，然后 `require bootstrap/app.php`，最后交给 `Bootloader::getInstance()->boot($app)`。
2. **`bootstrap/app.php`**（[bootstrap/app.php](bootstrap/app.php)）：`new \Leantime\Core\Application(APP_ROOT)`，绑定 HttpKernel / ConsoleKernel / ExceptionHandler / IncomingRequest 单例。
3. **`Leantime\Core\Application`**（[Application.php](app/Core/Application.php)）继承 Laravel `Foundation\Application`：
   - 重设各路径（`app/`、`config/`、`public/`…），命名空间 `Leantime\`；
   - 注册基础服务提供者（Events、Log、Context、Routing）；
   - `boot()` 时**提前**调用 `Event::discoverListeners()`（比 Laravel 默认更早），再触发 `beforeBootingServiceProviders` / `afterBootingServiceProviders` 事件。
4. **`Bootloader`**（[Bootloader.php](app/Core/Bootloader.php)）：捕获请求 → Web 走 HttpKernel / CLI 走 ConsoleKernel。
5. **HttpKernel**（[HttpKernel.php](app/Core/Http/HttpKernel.php)）：
   - bootstrappers：LoadEnvironmentVariables → **LoadConfig**（自定义）→ HandleExceptions → RegisterFacades → RegisterProviders → BootProviders；
   - **16 个全局中间件**（顺序见 2.4）；
   - 双层管道：核心中间件 → 插件中间件（`plugins_middleware` 过滤器）→ 路由分发。
6. **路由分发**（`findAndDispatchToRouter`）：先试 Laravel 路由（5 个域有 `routes.php`），`NotFoundHttpException` 时**回退到旧 Frontcontroller** 约定式路由（绝大多数请求走这里）。

## 2.4 中间件栈（严格顺序）

来自 [HttpKernel.php:36-79](app/Core/Http/HttpKernel.php#L36)：

| # | 中间件 | 职责 |
|---|---|---|
| 1 | `TrustProxies` | 代理信任校验（`LEAN_TRUSTED_PROXIES`） |
| 2 | `StartSession` | 会话启动，乐观并发写回 + 锁；API/CRON 请求用内存 array 驱动 |
| 3 | `Installed` | 未安装则跳 `/install` |
| 4 | `Updated` | DB 版本落后则跳升级页 |
| 5 | `LoadPlugins` | 触发 `pluginsEvents` 事件，加载用户插件的 register.php 与路由 |
| 6 | `InitialHeaders` | 安全头（CSP、X-Frame-Options），可被插件过滤 |
| 7 | `AuthCheck` | 登录门禁：web guard 链 + API Bearer/Key 校验 + 2FA 跳转 + 公开路由白名单 |
| 8 | `AuthenticateSession` | 密码哈希变更校验、remember cookie、构造 `session('userdata')` |
| 9 | `RequestRateLimiter` | 限流（登录 20/min、API 120/min、MCP 300/min、通用 2000/min，可 `LEAN_RATELIMIT_*` 覆盖） |
| 10 | `HandleCors` | CORS |
| 11 | `ValidatePostSize` | POST 体积校验 |
| 12 | `TrimStrings` | 去空白（密码除外） |
| 13 | `ConvertEmptyStringsToNull` | 空串转 null |
| 14 | `SetCacheHeaders` | 缓存头 + ETag |
| 15 | `Localization` | 语言、时区、日期格式、CarbonImmutable 宏 |
| 16 | `CurrentProject`（域中间件） | 设置当前项目上下文（非 HTMX/API 请求） |

> 注意：CSRF 校验**未全局启用**（历史上 ~82 个旧表单无 token，现已全部迁移 Blade，但代码仍保留注释说明按需启用），见 [HttpKernel.php:62-64](app/Core/Http/HttpKernel.php#L62)。中间件别名在 `middlewareAliases`（`auth`、`throttle` 等）。

## 2.5 领域驱动分层约定

每个领域模块（`app/Domain/{X}/`）的标准结构：

| 子目录 | 职责 | 继承/约定 |
|---|---|---|
| `Controllers/` | 页面控制器，HTTP 动词方法 `get($params)` / `post($params)` | `Core\Controller\Controller` |
| `Hxcontrollers/` | HTMX 局部刷新控制器，`protected static string $view` 指向 Blade partial | `Core\Controller\HtmxController` |
| `Services/` | 业务逻辑 + JSON-RPC API 面（`@api` 注解方法可被 RPC 调用） | `Core\Domains\BaseService`（推荐）或 `DomainService` 接口 |
| `Repositories/` | 数据访问（Query Builder + 少量原生 SQL） | `Core\Db\Repository` |
| `Models/` | 简单数据结构（public 属性，非 ORM 实体） | — |
| `Permissions/` | 权限词汇表常量 | `ProvidesPermissions` |
| `Templates/` | Blade 模板（`partials/`、`components/`、`submodules/`） | 命名空间 `{x}::` |
| `Js/` | 领域 JS（`leantime.{x}Controller` 命名空间） | IIFE 模块模式 |
| `Events/` | 领域事件类（类式事件） | `LeantimeEvent` |
| `Tools/` | MCP AI 工具（Calendar/Comments/Goalcanvas/Projects/Tickets/Timesheets 有） | `Laravel\Mcp\Server\Tool` |
| `Htmx/` | HTMX 事件枚举（`lt:{domain}:{entity}.{verb}`） | `HtmxEvent` |
| `register.php` | 事件监听器/定时任务注册入口 | 启动时自动 include |
| `routes.php` | 原生 Laravel 路由（可选，仅 5 域使用） | `RouteLoader` 自动加载 |
| 其他 | `Middleware/`、`Composers/`、`Listeners/`、`Support/`、`Commands/`、`Guards/`、`Enums/`、`Models/`、`Contracts/`、`Workers/`、`Jobs/` | 按需 |

**分层铁律**（[CLAUDE.md:797-801](CLAUDE.md#L797)）：Controller 只调 Service 不调 Repository；Service 可调 Repository；跨域 Service 调用需小心循环依赖；Service 负责校验输入并抛异常。

## 2.7 三个请求类型

由 `RequestTypeDetector` 自动识别（[HttpKernel.php](app/Core/Http/HttpKernel.php) 与 [Frontcontroller.php:96-101](app/Core/Controller/Frontcontroller.php#L96)）：

- **IncomingRequest**：标准 Web 请求。
- **ApiRequest**：API 请求（`/api/*`），额外提供 `getAuthorizationHeader()` / `getAPIKey()` / `getBearerToken()`。
- **HtmxRequest**：带 `HX-Request` 头的请求，额外提供 `isBoosted()` / `getTarget()` / `getTriggerName()` 等；`/hx/...` URL 前缀也路由到 Hxcontrollers。
