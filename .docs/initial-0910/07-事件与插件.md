# 07 事件与插件

## 7.1 事件系统（WordPress 风格 hooks）

实现：[EventDispatcher.php](app/Core/Events/EventDispatcher.php)（883 行），实现 Laravel `Dispatcher` 接口但提供双机制：

| 机制 | 语义 | API |
|---|---|---|
| **事件（Events）** | 即发即忘的通知 | `self::dispatch_event('ticket_created', $payload)` |
| **过滤器（Filters）** | 数据管线，串行透传可修改 | `$result = self::dispatch_filter('beforeReturnAllPlugins', $data, $params)` |

**命名约定**：字符串事件名由 `DispatchesEvents` trait 从类名+方法名自动生成：

```
leantime.domain.tickets.services.tickets.updateTicket.ticket_updated
       ↑ 模块       ↑ 类路径小写转点      ↑ 方法    ↑ 具体事件
```

> ⚠️ 移动类会改变其全部字符串事件名（这是官方在向类式事件迁移的原因）。当前仅 [Files/Events/FileUploaded.php](app/Domain/Files/Events/FileUploaded.php) 是类式事件样板；Tickets 域有 9 个类式事件（TicketCreated/Updated/Deleted、MilestoneCreated/Updated/Deleted、StatusLabelsUpdated、TicketListFilter、TodoWidgetTasksFilter），通过 `InteractsWithEvents` trait 的 `dispatch()` 同时双发 legacy 字符串名。

**注册监听**（在域的 `register.php` 中）：

```php
// 类式监听（调用 handle()）
EventDispatcher::add_event_listener('leantime.domain.projects.services.projects.notifyProjectUsers.notifyProjectUsers', NotifyProjectUsers::class);

// 闭包 + 通配符
EventDispatcher::addEventListener('leantime.domain.auth.*.userSignUpSuccess', function ($params) { ... });

// 过滤器 + 优先级（数值小先执行）
EventDispatcher::add_filter_listener('leantime.domain.menu.repositories.menu.getMenuStructure.menuStructures.project', fn($menu) => $menu, 50);
```

**模式匹配**：`*`（任意串）、`?`（单字符）、`{RGX:...:RGX}`（内联正则）。匹配结果带缓存（版本计数器，[EventDispatcher.php:74-103](app/Core/Events/EventDispatcher.php#L74)）。

**发现机制**：`Application::boot()` → `Event::discoverListeners()`（[Application.php:110](app/Core/Application.php#L110)）→ 扫描全部 `app/Domain/*/register.php` + 系统插件 register.php；用户插件 register.php 由 `LoadPlugins` 中间件在请求期加载（[EventDispatcher.php:538-586](app/Core/Events/EventDispatcher.php#L538)）。

**8 个有 register.php 的域**：Auth、CsvImport、Help、Install、Notifications、Plugins、Queue、Reports。用途：注册监听器/过滤器、**注册 cron 定时任务**（监听 `leantime.core.console.consolekernel.schedule.cron` 事件往 Schedule 塞任务）、生命周期钩子。

**Blade 指令**：`@dispatchEvent('name')`、`@dispatchFilter('name', $data)`。

**生命周期事件**（Bootloader/HttpKernel 派发）：`beforeBootingServiceProviders`、`afterBootingServiceProviders`、`request_started`、`request_terminated`、`beforeSendResponse`（过滤器）、`middleware`（过滤器）、`plugins_middleware`（过滤器）、`execute_action_start/end` 等。

## 7.2 插件系统

### 目录与形态
- 插件物理位置：`app/Plugins/{PluginName}/`（[Plugins.php](app/Core/Plugins/Plugins.php) 硬编码该路径）。OSS 仓库此处为空的 git submodule（商业插件私库）。
- **三种类型**：
  1. **系统插件**：`LEAN_PLUGINS` 环境变量指定（逗号分隔），启动即加载、不可禁用；
  2. **自定义目录插件**：直接放文件夹，开发最常用；
  3. **市场插件**：从 marketplace.leantime.io 下载的 **phar 包** + license key。
- 插件元数据来自其 **composer.json**（name/description/version），**没有 plugin.json**（[Services/Plugins.php:258-287](app/Domain/Plugins/Services/Plugins.php#L258)）。
- 插件主服务类：`Leantime\Plugins\{Studly}\Services\{Studly}`，实现 `PluginInterface`（install/uninstall/enable/disable 四钩子，[Contracts/PluginInterface.php](app/Domain/Plugins/Contracts/PluginInterface.php)）。
- 启用状态存 `zp_plugins` 表 + installation 缓存。

### 生命周期
`php bin/leantime plugin:install|enable|disable|remove|list {name}` → `Services\Plugins::performPluginAction()` → 主服务类对应钩子 → DB 状态更新。市场插件的 license 每日由 `plugins:checkLicense` 定时任务校验（[app/Domain/Plugins/register.php:10-36](app/Domain/Plugins/register.php#L10)）。

### 插件可注册的东西（Registration 服务，[Services/Registration.php](app/Domain/Plugins/Services/Registration.php)）
| 能力 | 方法 | 底层机制 |
|---|---|---|
| 路由 | 自带 `routes.php` | RouteLoader 自动加载（用户插件经 `pluginsEvents` 事件） |
| 控制器 | `Leantime\Plugins\{X}\Controllers|Hxcontrollers\{Action}` | Frontcontroller 约定 |
| 模板 | `Templates/` 目录 | ViewsServiceProvider 注册命名空间（支持 phar://） |
| 菜单项 | `addMenuItem([...], 'project', ['main', 'submenu-key'])` | 挂 `menuStructures.{section}` 过滤器 |
| JS/CSS | `addHeaderJs()/addFooterJs()/addCss()` | `afterLinkTags`/`beforeBodyClose` 过滤器 + Mix manifest 目录注入 |
| 中间件 | `registerMiddleware()` | 第二层管道 `plugins_middleware` |
| 语言 | `registerLanguageFiles(['en-US'])` | 语言加载器 |
| 命令 | `Command/` 目录 | ConsoleKernel 自动发现（[ConsoleKernel.php:125-149](app/Core/Console/ConsoleKernel.php#L125)） |
| 权限 | `Permissions/*Permissions.php` | PermissionRegistry 自动发现（[PermissionRegistry.php:91](app/Core/Auth/Permissions/PermissionRegistry.php#L91)） |
| 事件监听 | 自带 `register.php` | 加载插件时 include |

### JSON-RPC 门禁
`#[RequiresPlugin('pluginName')]` 属性可标在 RPC 方法/类上，禁用插件时返回 JSON-RPC 错误（[Jsonrpc.php:381-400](app/Domain/Api/Controllers/Jsonrpc.php#L381)）。

### 市场（Marketplace）
接口：`marketplaceUrl` + `ltmp-api`（列表/搜索/详情/下载 zip+phar/验证/停用）；`installMarketplacePlugin` 携带 `X-License-Key` / `X-Instance-Id` / `X-User-Count` 头下载解压。前端页面：`Plugins/Controllers/Marketplace.php`、`Hxcontrollers/Marketplaceplugins.php`。License 限制用户数，超限自动禁用（数据保留）。

## 7.3 二开建议

- **加功能**：优先类式事件（`app/Domain/{X}/Events/{Y}.php` 实现 `LeantimeEvent` + `EventVerb` 动词约束），同时保留 legacy 字符串双发以兼容旧监听。
- **让插件可扩展你写的代码**：在关键数据流上放 `dispatch_filter()`（例如返回列表前）。
- **不要在 Core 里写死业务钩子**；领域内部通过 register.php 自注册。
- 事件 payload 包装为 `['leantime' => ..., 'laravel' => ...]`（[EventDispatcher.php:193-194](app/Core/Events/EventDispatcher.php#L193)），监听回调一般取 `$payload['leantime']`。
