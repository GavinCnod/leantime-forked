## 10.3 关键机制备忘

1. **Canvas 数据共享警告**：zp_canvas/zp_canvas_items 全画布共用 id 序列 → 画布代码必须 fail-closed 按真实项目鉴权（见 [04-数据层](04-数据层.md) §4.2）。
2. **Tools 机制**：`Tools/` = MCP AI 工具（laravel/mcp），JSON-RPC 分发链也包含 `Plugins\X\Tools\X`，一个类可同时服务 MCP 与 RPC。
3. **register.php**：8 个域使用，注册监听器/过滤器/cron 任务。
4. **routes.php**：仅 5 域使用原生 Laravel 路由；其余 39 域走 Frontcontroller 约定。
5. **Services 是 API 面**：服务类公开方法 + `@api` 注解 = JSON-RPC 方法；`authorize()/can()/validate()` 是内置鉴权/校验工具。
