# 06 模板与前端

## 6.1 模板系统现状

- **Blade 已 100% 接管**：全库 0 个 `.tpl.php`，331 个 `.blade.php`（Domain 286 + Views 45）。旧 `.tpl.php` / `.sub.php` / `.inc.php` 扩展注册仅保留以兼容旧插件（[ViewsServiceProvider.php:66](app/Core/UI/ViewsServiceProvider.php#L66)）。
- 视图命名空间：`{domain}::` → `app/Domain/{Domain}/Templates`；`global::`/`globals::` → `app/Views/Templates`（[ViewsServiceProvider.php:412-450](app/Core/UI/ViewsServiceProvider.php#L412)）。
- 布局骨架（[app/Views/Templates/layouts/](app/Views/Templates/layouts/)）：`app.blade.php`（主布局）、`entry.blade.php`（登录）、`blank.blade.php`（HTMX 碎片）、`error.blade.php`、`registration.blade.php`。
- 渲染入口：`Template::display($template, $layout='app')`；HTMX 碎片用 `displayFragment($viewPath, $fragment)` + blank 布局（[Template.php:282](app/Core/UI/Template.php#L282)、:426-441）。
- View Composers（5 个全局）：App、Header、Footer、Entry、PageBottom，绑定 layouts/sections（[Composers/](app/Views/Composers/)）；域级 Composer 自动发现机制已就绪但尚无使用。

## 6.2 组件体系（三种类型，新代码优先组件）

1. **匿名组件（展示型）**：`app/Views/Templates/components/{name}.blade.php` → `<x-global::{name}>`；域级放 `app/Domain/{X}/Templates/components/` → `<x-{domain}::{name}>`。现有 23 个：statTile、statTiles、hx、badge、accordion、avatar、button、pageheader、periodpicker、subjectSwitcher、emojiinput、inlineLinks、inlineSelect、loader、loadingText、selectable、tabs、undrawSvg、kanban 子组件等。用法文档见 [components/COMPONENTS.md](app/Views/Templates/components/COMPONENTS.md)。
2. **HTMX 支撑组件**：`HxComponent` + `<x-global::hx :for="Class" :id="..." trigger="load"/>`，自动生成 hx-get + 懒加载 + 事件监听重拉（[components/hx.blade.php](app/Views/Templates/components/hx.blade.php)）。
3. **类组件**：带 PHP 类的 Blade 组件（`Leantime\Domain\{X}\View\Components\{Name}` 或 `Leantime\Views\Components`），仅当逻辑较重且非服务端抓取时使用；当前项目尚无实例。

## 6.3 前端 JS 架构

- **全局命名空间**：`leantime`（[public/assets/js/app/app.js](public/assets/js/app/app.js)），领域 JS 以 IIFE 挂载，如 `leantime.ticketsController = (function(){...})()`。
- **领域 JS**（33 个文件，`app/Domain/*/Js/`）：命名镜像后端——`{x}Repository.js`（AJAX）、`{x}Service.js`（逻辑）、`{x}Controller.js`（UI/DOM）。
- **打包**：`webpack.mix.js:73` 把 `app/Domain/**/*.js` 全部 glob 进 `compiled-app.{version}.min.js`，在 `<head>` 非 defer 全量加载（[header.blade.php:72](app/Views/Templates/sections/header.blade.php#L72)）——**没有代码分割**，改 JS 后必须 `npx mix` 重新构建。
- **按需重组件**：`$tpl->needsComponent('calendar'|'table'|'tiptap'|'gantt'|'chart')` 决定是否 defer 加载重量级 bundle（[Template.php:121-140](app/Core/UI/Template.php#L121)），控制器用 `requireComponents()` 声明。
- **fetch 约定**：需要异步数据时优先 JSON-RPC；必须 fetch 时 `fetch(url, { credentials: "include", headers: { 'X-Requested-With': 'XMLHttpRequest' } })`。

**主要 JS bundle**（全部经 [header.blade.php](app/Views/Templates/sections/header.blade.php) 加载）：
`compiled-htmx`(+extensions)、`compiled-frameworks`（jQuery+Bootstrap 2.x）、`compiled-framework-plugins`、`compiled-global-component`（Luxon/Moment/Tippy/Uppy/Croppie/GridStack/jsTree/Mermaid/Marked…）、`compiled-editor-component`（TinyMCE 5，3.6MB）、`compiled-calendar-component`（FullCalendar）、`compiled-table-component`（DataTables）、`compiled-gantt-component`、`compiled-chart-component`（Chart.js）、`compiled-app`。

## 6.4 HTMX 使用模式（异步交互首选）

- **事件两平面**（[CLAUDE.md:479-485](CLAUDE.md#L479)）：
  - 数据事件 `lt:{domain}:{entity}.{verb}`（过去时态），如 `lt:tickets:ticket.updated`，由域枚举定义（`app/Domain/{X}/Htmx/Htmx{D}Events.php`，实现 `HtmxEvent` + `InteractsWithHtmxEvents` trait），监听端 `hx-trigger="lt:tickets:ticket.updated from:body"`。
  - UI 命令事件 `lt:ui:{command}`（Notify、ModalClose 等），统一由 `Leantime\Core\Events\Htmx\HtmxUiEvents` 定义，**插件不得自行造 `lt:ui:*`**。
- **发射**：`$this->tpl->emit(EnumCase)` / `setHTMXEvent()` → 写入响应 `HX-Trigger` 头。
- **通知**：`$tpl->setNotification('已保存', 'success')` 自动发射 `HtmxUiEvents::Notify`，前端 growl 展示。
- **通用模式**：懒加载 `hx-trigger="revealed"`（`<x-global::hx>` 默认）、跨组件刷新 `from:body`、加载指示 `<x-global::loadingText>`、hover 预载 `preload="mouseover"`。
- 直连示例：[timerButton.blade.php:16](app/Domain/Tickets/Templates/partials/timerButton.blade.php#L16) `hx-patch="{BASE_URL}/hx/timesheets/stopwatch/start-timer/"`。
- 迁移期兼容：旧式 DOM 事件名与 `lt:` 新名通过 `HtmxEvents::LEGACY_ALIASES` 双发。

## 6.5 CSS 与主题

- **三层**：① 第三方（Bootstrap 2.x、jQuery UI、Font Awesome 6.5.2）；② 自定义组件样式 `public/assets/css/components/`；③ Tailwind 3.4（`tw-` 前缀，只启用 components+utilities，[app.less](public/assets/less/app.less)）。
- **设计令牌**：100+ CSS 自定义属性，颜色 `--accent1/--accent2/--primary-color/--primary-background/--secondary-background`，字号 `--font-size-*`，圆角 `--box-radius*`，阴影 `--min-shadow` 等。**新样式一律用变量，不硬编码色值**（深色模式自动适配）。
- **主题**：`public/theme/{default,minimal}/`，各含 `theme.ini`（名称、主/次色、是否支持取色器）+ `css/light.css` + `css/dark.css`；深色模式选择顺序 session → 用户设置 → cookie → light（[Theme.php:410-439](app/Core/UI/Theme.php#L410)）。
- **品牌色覆写**：`Theme::setAccentColors()` 写 session；[header.blade.php:127-136](app/Views/Templates/sections/header.blade.php#L127) 输出 `<style id="colorSchemeSetter">` 覆写 `:root` 的 `--accent1/2` 并计算 WCAG AA 对比度。Tailwind 的 `tw-text-primary` 等类映射到这些变量（[tailwind.config.js:15-21](tailwind.config.js#L15)），**改主题色无需重新构建 CSS**。

## 6.6 构建（详见 [11-构建测试与部署](11-构建测试与部署.md)）

- `npx mix`（dev）/ `npx mix --production`（prod）→ 输出 `public/dist/`（gitignore，仅 `mix-manifest.json` 入库）。
- 模板中 JS/CSS 引用**硬编码路径 + 文件 mtime 版本号**（header.blade.php:21-30），不依赖 manifest（manifest 供 API/插件用，[Core/Support/Mix.php](app/Core/Support/Mix.php)）。
- 改前端后提交前务必构建，否则 CI/部署拿不到新产物。
